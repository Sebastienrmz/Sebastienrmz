## Essayer les projets

**Windows** : télécharger le ZIP, l’extraire entièrement, puis ouvrir `Tester.bat`. Aucun compilateur ni installation de Python n’est nécessaire pour ces versions.

- [Filtres d’images](https://github.com/Sebastienrmz/projet-C/releases/latest)
- [Graphes de Markov](https://github.com/Sebastienrmz/projet-cP2/releases/latest)
- [Automates finis](https://github.com/Sebastienrmz/automates-finis/releases/latest)
- [Green Ball](https://github.com/Sebastienrmz/projet-transverse/releases/latest)

**Android** : [installer la démonstration E-Senior](https://github.com/Sebastienrmz/e-senior#essayer-lapplication). Sur ordinateur, utiliser un émulateur Android.

**Navigateur** : [ouvrir le site EFREI](https://sebastienrmz.github.io/projet-web1/). Le formulaire de contact est une démonstration sans envoi.

**MySQL** : [lancer le fichier de démonstration de la base de voyages](https://github.com/Sebastienrmz/sql-reservation-voyages#essayer-avec-un-seul-fichier).
